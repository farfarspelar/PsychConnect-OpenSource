## Audio

`app/src/main/res/raw/button_click.wav` is an original procedural sound effect created for PsychConnect using [`tools/generate_button_click.py`](tools/generate_button_click.py). The script synthesizes tones and seeded noise; it uses no recordings or external samples. The WAV is offered under CC0 1.0 as described in [AUDIO_LICENSE.md](AUDIO_LICENSE.md).
